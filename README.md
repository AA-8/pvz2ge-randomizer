This is a rough, rough draft of a Plants vs. Zombies 2: Gardendless Archipelago randomizer.

It contains nothing directly tied to Archipelago; neither server or clientside. For what is there, it works on both the latest (v1.12.1) web version and desktop versions with gpNext patched in.

## What is there?
Plant stat randomization, a rudimentary system for lowering the duration between daily events, faster forward, and customizable Sun collection amounts.

## How do I run it?
I personally just paste it into the developer console, but it could probably also run as a TamperMonkey/ViolentMonkey script.

I envision it could run as a gpNext mod under "jsModding" - but I can't find any information online about how that works.
